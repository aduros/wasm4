# Last Train Home

A simple hex-based exploration puzzle game written in Zig (v0.16.0) for the [Zero Sugar Added](https://codeberg.org/zero-sugar-added/jam/src/branch/main/editions/1-WASM-4.md) game jam (version 1). The theme was "Full Steam Ahead" which is why the train theme is a bit shoehorned in. :)

Source available here: https://codeberg.org/rdunnington/last_train_home
