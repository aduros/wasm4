# Number Slide

Number Slide is a classic 15-puzzle game developed with WASM-4.

The objective is to arrange the numbered tiles in ascending order by sliding them into the empty space.

## Controls

- Arrow Keys: Move the tiles
- X: Start the game

Good luck and have fun!
